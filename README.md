# PLAYMAX Uzbekistan bot (@playmax_uz_bot)

Services for the Telegram channel @playmax_box: catalog, orders, price requests, profit calculator,
service requests, strongest-punch challenge, showroom visits, delivery quotes, live video requests,
customer showcase and dealer applications. All requests are forwarded to the admin.

- `bot/bot.py` — long-polling bot (GitHub Actions shifts, `.github/workflows/bot.yml`)
- `bot/data.py` — texts, catalog, links
- `bot/weekly.py` — weekly TOP-5 post (Sunday 20:00 Tashkent)
- Secret: `TG_UZ_TOKEN`
